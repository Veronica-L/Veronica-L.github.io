# Kiki's Blog · 个人博客交互原型

在此目录执行 `npm run dev`，打开 http://127.0.0.1:4173 。无需安装依赖。

## 可体验的内容

- 首页、文章详情和分类筛选。
- 标签漫游、按年月归档、全文搜索。
- 日记时间线和博客／日记编辑器，支持简单 Markdown。
- 本地草稿保存，已保存文章与日记在刷新后保留。
- 日记支持多张图片插入正文、缩略图预览与移除；插图随草稿恢复，保存日记后自动进入照片墙的「日记」目录。
- 从日记相册放大图片后，可返回对应日记；前后切图保持在当前相册中。
- 照片分类、照片放大和方向键切换。
- 三段可播放的原创合成氛围音、切歌、暂停、进度、静音。
- 本次会话内导入本地音频，保存网易云歌单链接。
- 明暗主题切换、手机与电脑布局。

## 原型边界

公开页面使用静态文件展示，并连接独立管理后台。原有文章、日记和摄影为模板示例；后台发布的内容会加入公开页面。占位摄影来自 Unsplash，拼贴参考图由用户提供。音频为本原型程序生成的合成氛围音。

文章、日记、草稿、主题及歌单链接保存在当前浏览器的 localStorage 中，不会上传或公开。日记图片保存在当前浏览器 IndexedDB 中，日记与草稿保留图片 ID。照片墙的「日记」是浏览器内的相册目录，并非系统磁盘目录。清理浏览器数据会丢失这些内容和图片。导入音乐只在本次会话有效。

网易云账号、歌单读取和原曲播放尚未接入。新版写作通过 GitHub 登录后台，草稿与未发布插图存入 Cloudflare D1，点击发布才写入 GitHub 并部署。旧版浏览器内保存的记录不会自动上传。后台使用和部署说明见 [ADMIN.md](ADMIN.md)。

## 设计参考

- [Frud's Blog](https://www.aibrium.cn/)：分类、标签和时间索引的组织思路。
- [lololowe 的博客](https://blog.lololowe.com/)：主页的个人空间感、半透明层次与音乐入口。

当前版本采用米白纸张、钴蓝、橙红与复古摄影拼贴。首页以用户提供的五张参考图片作为本地视觉素材；未修改原始图片，保留原图署名与水印。页面介绍采用直接的栏目名称和功能说明。此前的森林毛玻璃样式保留在 styles.css 中作为旧版参考，当前页面使用 art-style.css。

## 字体

经浏览器核对，与 https://www.aibrium.cn/ 首页正文和 h1 实际生效的 font-family 一致：ui-serif、Georgia、Cambria、Times New Roman、Times、serif。中英文正文和标题采用同一栈，由浏览器和操作系统选择中文回退字体；没有额外下载正文 web 字体。
